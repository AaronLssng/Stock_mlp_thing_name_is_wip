# Changelog

## [0.1.0] - 2026-06-24

### Added
- C library for high-performance binary stock data storage
- MLP neural network for stock price prediction
- Interactive CLI fetcher for downloading stock data
- Custom binary file format (64-byte header + 36-byte bars)
- Append operations for incremental data updates
- Yahoo Finance integration via yfinance
- Test suite for system verification
