# Contributing

We welcome contributions! Here's how to contribute.

## Coding Style

- **Avoid OOP** unless an external library requires it
- Keep classes minimal - prefer functions and modules
- Follow PEP 8 for Python
- Write clear, self-documenting code
- Add docstrings for public functions

## How to Contribute

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Submit a pull request
5. Your PR will be reviewed before merging

## Pull Request Guidelines

- Keep PRs focused on one feature or fix
- Test your changes
- Update documentation if needed
- Your code will be reviewed before merging

## Questions?

Open an issue on GitHub.
