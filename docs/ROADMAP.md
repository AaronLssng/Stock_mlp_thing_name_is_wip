# Roadmap

## REPL & Commands
- Dot-command system (.open, .fetch, .view, .train, .simulate)
- Lua scripting layer for REPL interface
- Persistent sessions with context-aware commands
- .help for command overview, .help <command> for details
- Custom query language for data operations

## Data Sources
- Yahoo Finance (existing)
- CSV import/export
- Additional sources (to be determined)

## Training Tools
- Integrated .train command (MLP)
- Monte Carlo simulations (.simulate)
- Strategy backtesting

## Strategy System
- User-defined trading strategies
- Signal generation from trained models

## Scheduling
- Automated data fetching
- Scheduled retraining

## Modding
- Lua addon/mod support (future)
